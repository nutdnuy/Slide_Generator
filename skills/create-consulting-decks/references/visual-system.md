# Visual System

Use this reference before rendering a consulting-grade deck.

## Principles

- Use a restrained boardroom style unless the user specifies a more expressive direction.
- Prioritize executive scanning: headline first, evidence second, implication third.
- Use original design language. Do not copy a named firm's template, exact palette, logos, page furniture, or proprietary iconography.
- Prefer white or near-white backgrounds for analytic decks. Use dark backgrounds sparingly for title, section divider, or high-drama executive slides.

## Layout

- Use a consistent grid, margins, footer, page number, and source treatment.
- Reserve the top 15-25% for the governing message.
- Put evidence in one dominant zone: chart, table, matrix, map, or process.
- Use real source figures/photo panels when they add evidence credibility: framework diagrams from papers, report screenshots, trading-result charts, product photos, or market-map snapshots. Crop tightly, frame consistently, and write the interpretation in renderer text rather than relying on tiny embedded labels.
- Use annotations to explain charts instead of making the viewer infer the answer.
- Keep one focal chart or table per slide unless building an executive summary.

## Typography

- Use clean sans-serif fonts available on the machine. Good defaults: Aptos, Arial, Helvetica, Inter if available.
- Use a large takeaway title and smaller evidence labels.
- Avoid long paragraphs. Convert to bullets, callouts, or table rows.
- For Thai text, keep lines shorter and prefer editable PPT text over generated image text.

## Color

- Keep the dominant palette neutral: white, charcoal, cool gray.
- Use one accent color for recommendation or emphasis and a second accent only for contrast.
- Avoid rainbow charts unless categories require it.
- Use red/amber/green only when the semantic meaning is clear.

Suggested default palette:

- Background: `F7F8FA`
- Text: `1F2933`
- Muted text: `697586`
- Grid line: `D7DEE8`
- Accent: `1264A3`
- Secondary accent: `00A88F`
- Warning: `B7791F`
- Risk: `C2410C`

Institutional finance seminar option:

- Use for asset owner, official institution, portfolio construction, macro, research, or board seminar decks.
- Use deep navy section dividers, white analytic pages, teal subtitles, pale geometric blocks, and strong footer/source discipline.
- Keep the layout dense but calm: large headline, accent subtitle, one dominant evidence object, then sources and page mark.
- Use generic project marks only; do not copy real asset-manager logos or exact proprietary templates unless the user owns that brand context and explicitly supplies the assets.

## Chart Grammar

- Make chart titles state the insight, not the chart type.
- Label units and time periods.
- Sort bars when the ranking is the message.
- Use direct labels when possible; avoid legends that force eye travel.
- Use waterfall/bridge charts for changes, stacked bars for composition, line charts for trend, scatter or 2x2 for positioning.
- Keep charts editable when numbers matter.

## Tables

- Use tables for exact comparisons, not visual decoration.
- Keep columns few and meaningful.
- Use a verdict row or rightmost implication column when the table supports a decision.
- Highlight only the row/column tied to the recommendation.

## Footer

Include source and slide number. If assumptions matter, include them in a note or appendix rather than hiding them.
