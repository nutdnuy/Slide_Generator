# Image Prompt Patterns

Use image generation only when the visual itself carries the message and exact text is not critical.

## Required Prompt Phrase

Every generated slide image prompt must include:

`ONE single 16:9 finished presentation slide image`

Also specify:

- no contact sheet
- no multi-slide preview
- no watermarks
- no logos from real consulting firms
- clean empty space for editable text overlay when text accuracy matters

## Default Consulting Hero Prompt

Create ONE single 16:9 finished presentation slide image for a consulting-grade executive strategy deck. Original premium boardroom visual system, clean grid, restrained neutral palette with one blue-green accent, high contrast, spacious layout, no logos, no watermarks, no contact sheet, no multi-slide mockup. Visual metaphor: [describe business concept]. Leave clean negative space in the upper-left for an editable title overlay.

## Conceptual Business Visual

Create ONE single 16:9 finished presentation slide image for a professional consulting deck. Show [market/customer/operations/technology concept] as a realistic but polished business visual. Use a disciplined composition, subtle data-inspired geometry, neutral background, one accent color, no readable tiny text, no real company logos, no watermarks, no collage, no contact sheet.

## Background-Only Slide Visual

Create ONE single 16:9 presentation slide background image for a professional consulting deck. No title, no body text, no numbers, no chart labels, no logos, no watermark. Use [visual concept] as a subtle executive visual system with clean negative space for text overlay, disciplined grid, restrained navy/teal/gray palette, high contrast, and no multi-slide preview.

## Section Divider

Create ONE single 16:9 finished presentation slide image for a strategy consulting section divider. Minimal executive style, strong focal object related to [section theme], large clean negative space, subtle grid, neutral charcoal and off-white palette with one accent color, no logos, no watermarks, no extra panels, no multi-slide preview.

## Thai Text Guidance

Avoid generating long Thai text inside images. Prefer background-only images and overlay Thai text in editable PowerPoint. If text must be in the image, keep it to 1-4 short words and inspect spelling manually.

## Reject And Regenerate If

- It shows more than one slide.
- It looks like a mockup on a laptop or wall instead of the finished slide.
- It contains gibberish, malformed Thai, fake logos, watermarks, or unreadable UI text.
- The main subject blocks the planned text area.
- It violates the deck's color or layout system.
