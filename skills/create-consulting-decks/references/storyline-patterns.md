# Storyline Patterns

Use this reference when building the narrative spine of a consulting-grade deck.

## Core Standard

Start from the decision. A consulting deck should make it easy for the audience to answer: "What should we do, why, and what changes next?"

Prefer a recommendation-first storyline when the answer is known:

1. Recommendation
2. Why now
3. Evidence
4. Economics or impact
5. Risks and mitigations
6. Implementation path
7. Decision required

Use SCQA when the audience needs context before the recommendation:

- Situation: stable context the audience accepts.
- Complication: what changed, broke, or created urgency.
- Question: the decision or strategic question.
- Answer: the recommendation, thesis, or path.

## Pyramid Principle

Make the governing message the top of the pyramid. Supporting points must be mutually exclusive, collectively sufficient enough for the decision, and ordered by executive importance.

Good governing message:

- "A focused premium entry is attractive, but only if we partner for distribution and delay mass-market expansion."

Weak governing message:

- "Market Entry Analysis"

## Hypothesis-Driven Flow

When data is incomplete, state the working hypothesis and what would disprove it.

Use this sequence:

1. Hypothesis
2. Critical assumptions
3. Evidence gathered
4. Gaps and sensitivities
5. Recommendation or next analysis

## Issue Trees

Use issue trees to structure analysis, not to decorate slides. Each branch should be testable.

Common trees:

- Growth: market size, share capture, pricing, retention, channel capacity.
- Profitability: revenue, cost of goods, operating cost, capital intensity, risk.
- Market entry: attractiveness, ability to win, route to market, economics, execution risk.
- Transformation: ambition, operating model, capability gaps, roadmap, governance.

## Slide Flow Patterns

Executive recommendation deck:

1. Executive summary
2. Decision context
3. Market or problem sizing
4. Strategic options
5. Recommended option
6. Financial/operational impact
7. Risks and mitigations
8. Roadmap and decision ask

Board update deck:

1. Decision or status headline
2. Performance snapshot
3. Key variance drivers
4. Strategic implications
5. Risks and decisions
6. Appendix or backup

Market entry deck:

1. Entry recommendation
2. Market attractiveness
3. Customer/segment priorities
4. Competitive landscape
5. Route-to-market options
6. Financial case
7. Risk mitigation
8. Launch roadmap
