# Chart Rules

## Daily Market Charts

- Use normalized line charts when comparing price paths across assets.
- Use grouped return bars for 1D / 5D / 20D comparisons.
- Use return-versus-volatility scatter to explain risk-adjusted positioning.
- Use tables for exact values; charts for pattern recognition.

## Readability

- Include date range and units on every chart.
- Label symbols directly.
- Use green for positive returns, red for negative returns, and a neutral color for axes/grid.
- Keep chart subtitles factual and short.

## QA

- Latest date must be shown.
- Every symbol in a chart must have data.
- Do not mix stale and fresh data without a visible cache note.
- If a symbol has fewer than 60 observations, calculate what is available and label the date range.
