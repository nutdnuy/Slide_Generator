# 7-Day Investor AI Workbench SOP

## Goal

Use the same workflow with 5 watchlist items within 7 days.

## Day 1: Pick the Watchlist

- Choose 5 assets or themes.
- Fill `watchlist.csv`.
- Write one research question for each item.

## Day 2-3: Source Collection

- Add at least 2 sources per asset.
- Fill the source log.
- Mark each claim as fact, interpretation, or assumption.

## Day 4: Thesis Draft

- Create thesis cards for the top 2 assets.
- Add bull case, bear case, risks, and kill criteria.

## Day 5: Risk Review

- Ask Claude to challenge each thesis.
- Add missing evidence and red flags.

## Day 6: Dashboard Review

- Import updated CSV into the dashboard.
- Sort by score.
- Filter high-risk items.
- Export notes.

## Day 7: Investment Committee Note

- Write a short weekly memo:
  - What changed?
  - Which claim is weakest?
  - What must be verified next?
  - What should be removed from the watchlist?

## Rule

The dashboard helps organize research. It does not produce buy/sell decisions.
