# Final Workshop Checklist

## Learner Artifacts

- [ ] Case brief completed.
- [ ] Research question map completed.
- [ ] Source log has at least 3 sources or sample sources.
- [ ] At least one thesis card completed.
- [ ] `watchlist.csv` exists and can be opened.
- [ ] `investor-dashboard.html` opens in browser.
- [ ] Dashboard imports CSV successfully.
- [ ] Dashboard shows symbol, name, thesis, risk level, score, next action, and notes.
- [ ] Dashboard has risk filter, search, sort, and export notes.
- [ ] No dashboard output creates a buy/sell recommendation.

## Understanding Check

- [ ] Learner can explain fact vs interpretation vs assumption.
- [ ] Learner can identify weak evidence.
- [ ] Learner can describe what data would change the thesis.
- [ ] Learner can give Codex a clear build brief.
- [ ] Learner can test AI-generated output before using it.

## Facilitator Acceptance

- [ ] 3-minute final presentation completed.
- [ ] Learner can open and reuse the workspace folder.
- [ ] Learner has a 7-day review plan.
